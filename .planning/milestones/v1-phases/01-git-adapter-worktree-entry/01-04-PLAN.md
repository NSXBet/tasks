# Plan 01-04: One git runner — fold surface/git.ts and hooks.ts spawnSync into @tasks/git (gap closure)

<objective>
Close verification gap 2 (SC3/GIT-01): delete the second adapter `packages/surface/src/git.ts` and the ad-hoc `spawnSync("git")` runner in `packages/cli/src/hooks.ts` (L41-45 helper, L737 `gitAddFile`), routing both through `@tasks/git`.

Key constraint: surface's `nodeRunner` exists because `@tasks/surface` also loads under pi (node) — `rootFrom` is called from `packages/pi-extention/src/watch/child-entry.ts`. `@tasks/git`'s `bunRunner` uses `Bun.spawn`, so the adapter's default runner must become runtime-portable before discover.ts can switch. Hooks need synchronous git (`isGitTrackedFile` etc. are sync), so the adapter gains a sync call shape in the same runner module.
</objective>
