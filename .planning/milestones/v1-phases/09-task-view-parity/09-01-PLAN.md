<feature>
  <name>Shared task-view model (`@tasks/review/taskview`)</name>
  <files>packages/review/src/core/taskview/model.ts, packages/review/src/core/taskview/model.test.ts, packages/review/package.json</files>
  <behavior>
    patchFileStats:
    - a patch with one modified file (2 hunks: +3/−1 and +1/−0) → `[{ path: "src/a.ts", status: "M", additions: 4, deletions: 1, hunks: [{additions:3,deletions:1,…},{additions:1,deletions:0,…}] }]`
    - `new file mode` → status `A`; `deleted file mode` → `D` (path from the `---` side); `rename from/to` → `R` with the new path; `Binary files … differ` → entry with zero counts and no hunks
    - `""` and `null` → `[]`
    changesTree:
    - files `src/middleware/auth.ts` (M), `src/uploader/retry.ts` (M) with no threads → rows `src/`(depth 0), `middleware/`(1), `auth.ts`(2, M), `uploader/`(1), `retry.ts`(2, M); every row `needsReview: true`
    - a file whose threads are all resolved/dismissed (≥1 thread) → `needsReview: false`; its directory stays true only if a sibling still needs review
    - a file with an open or sent thread → `needsReview: true`
    minimapBars:
    - hunks of sizes 10 and 5 → sizes 1 and 0.5; `+1/−4` → tone `del`; `+4/−1` → `add`; order follows files then hunks
    - no hunks → `[]`
    artifactGroups:
    - evidence blob (image) + path attachment `task.md` (not in changes) + path attachment `src/a.ts` (changed, M) + `src/new.ts` (changed, A) → counts `{ src: 1, edit: 1, new: 1, other: 1 }`; `IN CHANGES` holds `src/a.ts`, `src/new.ts`; `UNREFERENCED` holds the evidence row and `task.md`
    - comment counts: two open threads with `evidenceId` = the blob id → that row `comments: 2`; a resolved thread does not count
    docBlocks:
    - `# T\n\npara one\npara two\n\n```ts\na\n\nb\n```\n` → `[{line:1,endLine:1}, {line:3,endLine:4}, {line:6,endLine:10}]` (the fence keeps its inner blank line)
    - trailing blank lines produce no empty block
  </behavior>
  <implementation>Pure TypeScript, type-only imports from `@tasks/domain` and `../review/commentStore.js`. No fs, no git, no DOM.</implementation>
</feature>
