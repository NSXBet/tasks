web and the agents.

when a task is ready for review, approved, rejected or commented, **so that** TUI and web show the same live state
from one stream.

- `openTuiStore(root)` (packages/tui/src/store.ts:410-439) implements `watch(onEvent, intervalMs = 1000)` as a
  board-signature poll: every second it reloads the full board and emits a synthetic `issue.updated` with
  `seq: 0` when `boardSignature` changes — not real watch events, no kinds, no comment/status data.

  spawning a global daemon from tests.
