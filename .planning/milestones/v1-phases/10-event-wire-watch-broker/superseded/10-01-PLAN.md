**As an** agent or a human with several watchers open, **I want** the daemon to poll each workspace once and fan
the events out to every subscriber with its own filter, **so that** one or many tasks can be watched by many agents
at once without N poll loops racing each other.

Implements D-01 at the broker layer (WIRE-01, ROADMAP SC-1). Output: a reusable hub in `@tasks/surface`, the daemon
events host rebuilt on per-root hubs, tests.

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| local socket client → daemon | any local process that can open the user's socket can subscribe and name a root |
| subscriber callback → hub | one consumer's failure must not affect others |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-10-01 | Denial of service | hub fan-out | medium | mitigate | Subscriber callbacks run in try/catch; per-subscriber cap of `MAX_EVENTS_PER_TICK` per tick; one poll loop per root regardless of subscriber count (removes N-loop amplification). |
| T-10-02 | Tampering | `processWakeups` under N loops | medium | mitigate | One hub per root means one wakeup pass per tick; the previous per-subscription loops raced the same undefer writes. |
| T-10-03 | Information disclosure | `events.subscribe` root | low | accept | Socket lives in the user's temp dir with user permissions (existing model); `rootFrom(root) === root` check in `surfaceFor` still rejects non-workspaces. |
| T-10-04 | Denial of service | dead socket writes | low | mitigate | Writes guarded by `destroyed`/`writable`; socket `close` → `drop` unsubscribes; last unsubscribe stops the hub. |
</threat_model>
