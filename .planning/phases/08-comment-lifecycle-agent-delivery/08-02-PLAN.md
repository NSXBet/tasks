## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| keypress → task record | `x`/`D`/`S` write lifecycle moves to `metadata.reviewThreads` and `reviewCommentLog` |
| stored comment text → terminal | rail rows render bodies written by any surface |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-08-05 | Tampering | `S` send key | medium | mitigate | Send is only reachable from the full diff view (not the compact modal) and calls `sendOpen` with no id filter: it can only move `open` → `sent`, never resolved/dismissed, and the store refuses `sent` through `setThreadStatus`. |
| T-08-06 | Repudiation | TUI lifecycle moves | low | mitigate | `setThreadStatus` receives the TUI's resolved `actor`; the surface logs actor + time per move (tested in 08-01 Task 2). |
| T-08-07 | Spoofing | rail text | low | accept | OpenTUI `<text content>` renders strings as text cells, not escape sequences; bodies are truncated by `truncate`. Same exposure as Phase 4's rail. |
</threat_model>
