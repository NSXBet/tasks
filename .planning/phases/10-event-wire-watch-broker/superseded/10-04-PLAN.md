<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| event payload → SSE → browser | user-authored comment text and locations reach the page |
| browser → `/events` | any local page can open the stream (existing localhost model) |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-10-13 | Tampering | SSE frame framing | medium | mitigate | `data:` is a single `JSON.stringify` line, so newlines in bodies cannot inject extra SSE fields or events (same rule as `broadcastReview`). |
| T-10-14 | Spoofing | toast rendering (XSS) | medium | mitigate | Toast text goes through `textContent` only; strings clipped to 120 chars; no `innerHTML` with event data. |
| T-10-15 | Denial of service | refresh storms | low | mitigate | 100ms refresh debounce and one toast per 500ms; the hub caps events per tick (10-01). |
| T-10-16 | Information disclosure | stale workspace after repoint | low | mitigate | Unsubscribe-then-resubscribe on `open()`; test asserts the old workspace's events stop. |
</threat_model>
