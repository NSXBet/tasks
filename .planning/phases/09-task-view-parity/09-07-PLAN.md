## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| evidence blob → `<img>` | agent-uploaded bytes served with their stored mime |
| browser → `/api/review/:id/threads` | localhost write of comment bodies |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-09-15 | Tampering (XSS) | evidence served as `image/svg+xml` with script | medium | mitigate | the island renders evidence only through `<img>` (SVG scripts do not run in `<img>`); never `<object>`/`<iframe>`/`innerHTML`; the blob route keeps `cache-control: no-store` |
| T-09-16 | Tampering | evidence id in URLs and element ids | low | mitigate | ids come from the payload filter (`ev-[a-z0-9]{6}` shape); URLs built with `encodeURIComponent` |
| T-09-17 | Denial of service | island root destroyed by poll re-render while the modal is open | low | mitigate | task re-render skipped while `state.diffModal` is set; SSE uses `ReviewIsland.refresh` |
| T-09-SC | Tampering | npm/pip/cargo installs | high | mitigate | no package installs in this plan |
</threat_model>
