<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| git output → record | `deriveChangeset` / `gitBranchHead` output becomes `metadata.report` |
| record → chat/terminal | the stat card is printed into agent sessions and terminals |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-11-01 | Information disclosure | stat card in chat | medium | mitigate | The card carries only counts, the task id and two links. No file contents, no patch, no file paths. Tests assert the absence of `diff --git` / `@@` / committed line text. |
| T-11-02 | Tampering | `metadata.report` read path | low | mitigate | `readReportStat` accepts only non-negative integers for the four counts and a string `at`/`head`; anything else is treated as absent (falls to the next ladder rung). |
| T-11-03 | Spoofing | stale numbers shown as current | low | mitigate | Every cached rung sets `stale: true` and the card prints the `stale — from finish report <at>` pill; only the live and closed-snapshot rungs render without it. |
| T-11-04 | Denial of service | finish derivation failure | low | accept | The stamp is non-fatal: a failed derivation writes no `report`, and finish still completes (FIN-01 unchanged). |
</threat_model>
