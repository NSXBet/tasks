<objective>
Make the web diff live through the existing `/events` SSE stream (CONTEXT "Live + edit", here D-02): a server-side
watcher on each task's worktree and on the repo's branch refs pushes a named `review` frame, and the review island
re-fetches its payload on that frame instead of the whole page reloading. Also switch the live web patch to the
working-tree form so the diff actually changes when worktree files change (today it is `base...HEAD`, commits only).

and the live half of WEB-02.
Output: watchers + SSE frame in server.ts, working-tree patch in review.ts, `refresh` on the island mount API, the
app.html listener, an e2e test, architecture.md update.

Decision IDs: 05-CONTEXT.md has unnumbered decisions; this phase numbers them in CONTEXT order —
D-01 Landing (task view first, open diff primary), D-02 Live (server watcher → `/events` → island refetch, no client polling),

D-05 Comments (existing `/api/review/:id/threads…` over `taskStoreCommentStore`). Discretion used here: debounce
250ms (worktree) / 150ms (refs); event name `review`; payload `{id, reason}`.
