Hunk 0.24.1 default keymap for these keys, read from the installed binary because `packages/review/src` doesn't
vendor `keymap.ts`. Each maps to its TUI adaptation:
- `s` `view.toggleFilesPane` → hide `HunkFileNav`.
- `l` `view.toggleLineNumbers` → `HunkDiffView showLineNumbers`.
- `z` `review.toggleHunkGap` ("expand or collapse context for the selected hunk") → whole-diff context toggle. The
  vendored `HunkDiffView` has no gap-expansion prop, so the patch is re-derived with more context. This deviates
  from hunk's per-hunk scope; note it in help and docs.
- `a` `view.toggleAgentNotes` → toggle the notes (thread) rail. tk has no separate agent-rationale source; the
  spec bar labels the key `a notes`.
- `t` `view.openThemeSelector` → cycle `HUNK_DIFF_THEME_NAMES` (no selector popup).
- `v` `review.startVisualSelection` / `y` `review.copySelection` → a hunk-granular range, because the view has no
  line cursor. The copy goes through OpenTUI `renderer.copyToClipboardOSC52`.
- `/` → file search. Hunk's review filter has no default key, and its `/` is search in the history view; the spec bar
  says `/ search`.

Keybar width: line 1 at two-space separators is 136 chars, so it fits the 139 usable columns at 140. That's why it
reads `s files`, not the mock's `s files pane` (141 chars).
