| task record → terminal | Thread bodies written by other surfaces (web, agents) are rendered in the TUI rail |

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |

| T-04-SC | Tampering | npm/bun installs | low | accept | No package installs. |
